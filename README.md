# qbo-integration

Public landing, terms, privacy, and disconnect pages for the internal
QuickBooks Online &harr; Salesforce/Litify integration operated by
Sam Aguiar Injury Lawyers.

These pages exist to satisfy the URLs the Intuit Developer production app
profile requires (host domain, launch URL, connect URL, disconnect URL, EULA,
privacy policy). The integration itself is a private back-office tool and is not
a public application.

Served via GitHub Pages:

| Intuit field          | URL                                                      |
|-----------------------|----------------------------------------------------------|
| Host domain           | `nthatf01.github.io`                                     |
| Launch URL            | `https://nthatf01.github.io/qbo-integration/`            |
| Connect / Reconnect   | `https://nthatf01.github.io/qbo-integration/`            |
| Disconnect URL        | `https://nthatf01.github.io/qbo-integration/disconnect/` |
| EULA / Terms          | `https://nthatf01.github.io/qbo-integration/eula/`       |
| Privacy Policy        | `https://nthatf01.github.io/qbo-integration/privacy/`    |
